用一句話、滑桿，或一張風景照，做出會動的像素桌布。

地區與生態（現實同步）

    選了地點後，物種、季節、配色（含清晨／黃昏／夜晚）都依當地決定。資料來自 Open-Meteo 與 GBIF，只在按按鈕或開即時同步時連線；位置只取到小數一位（約 10 公里）。

    水面與動態

    六步打磨（關掉看差別）

    風景照轉換

    把風景照轉成本產品的像素風格：減色、暗部偏藍綠亮部偏暖、往目前配色靠攏，並自動找出水面套上晃動、亮點與漣漪。

    照片只存在這個分頁。桌布網址（Plash）不會帶著照片；請用「錄影片」輸出無縫循環的影片。

    素材圖與像素化

    上傳的圖只存在這個分頁。要當桌布，請把圖放進 assets/ 並執行 npm run assets（見 assets/README.md）。

    圖片像素化

    任何圖片縮小、減色、抖動成像素畫；可去背後當成樹、石頭、地標放進場景。

    輸出與桌布

    設成 Mac 動態桌布

    1. 安裝免費的 Plash（Mac App Store）。
    2. Plash 選單 → Add Website → 貼上網址。
    3. 之後在這裡調整，重新複製網址即可。
