# Pixel Pond — 像素池塘動態桌布產生器

把「一片水面貼圖」逐步打磨成會呼吸的像素池塘（概念來自 SpriteCook 的
[pixel-art pond 教學](https://www.spritecook.ai/blog/pixel-art-pond-water-reflections-ripples)），
再用滑桿、色票、一句話描述客製，最後設成 Mac 動態桌布。

| 步驟 | 效果 |
|---|---|
| 1 | 依（平滑後）離岸距離分 3 段色：岸邊淺、池心深 |
| 2 | 依「離對岸幾行」分段提亮近側水面，映入天空 |
| 3 | 樹影倒置、壓到 55%、只留 3 個平色調（暗的贏）；前 3 行不動，之後逐行整像素錯開 |
| 4 | 只在近岸與側岸：泥上淺水、濕地壓到 82%、在 2↔3 px 間來回的拍岸短線 |
| 5 | 對岸保持暗：水線暗線、岸泥/岸草倒影 6 行、陰影裡的暗波紋、水線上下爬 |
| 6 | 5 格漣漪、1→3→5 px 的亮點、落葉（落→浮→沉）、荷葉上下動一像素並帶陰影 |

水面的數字照教學原文：10 色色階（森林配色時就是教學的色碼）、深淺 3/7 px、天空帶 14/28 行、倒影壓 55% 並以最暗 15% 與亮度 110 切 3 色、
倒影前 3 行不動 30 行後晃 2 px、對岸倒映 1/2/3/4/6 行、漣漪半徑 (1,0)→(8,4)、20 個亮點、每循環 2 片落葉與 1 滴水、荷葉 sin(phase(t,1)+1.7k) > 0.4 時下沉 1 px。

照教學的兩條規則：水面每個像素只從 10 色色階挑一色（從不混色，所以不糊）；
所有動作都在 5 秒循環內跑整數圈，錄成影片可以無縫重播。

面板上可以逐步開關，或按「對照」一鍵比較原始貼圖與六步完成版。

## 本機執行

不需要安裝任何套件，但要用本機伺服器開（程式是 ES modules，瀏覽器不允許從 `file://` 載入模組）：

```bash
npm run dev   # = python3 -m http.server 5173，打開 http://localhost:5173
npm test      # 渲染器與關鍵字解析的自我檢查（Node）
```

## 設成 Mac 動態桌布

1. 從 Mac App Store 安裝免費的 [Plash](https://sindresorhus.com/plash)。
2. 在面板按「複製桌布網址」（網址結尾帶 `wp=1`，會隱藏面板、填滿螢幕、依螢幕比例出圖）。
3. Plash 選單 → Add Website → 貼上網址。

其他選擇：「存 PNG」當靜態桌布；「錄影片」輸出 MP4（Safari）/ WebM（Chrome），給支援影片桌布的 App 使用。
FPS 上限調到 12–24 可以省電；視窗被遮住時瀏覽器會自動暫停動畫。

## 上線部署

純靜態檔案（`index.html`、`style.css`、`src/`、`assets/`），沒有建置步驟。把整個資料夾丟到
GitHub Pages / Netlify / Vercel / Cloudflare Pages 任一處即可。部署後的網址同樣可以直接貼進 Plash。
所有設定都存在網址 hash，所以分享作品 = 分享網址，不需要後端。

這個 repo 本身就是部署內容：開啟 GitHub Pages（Settings → Pages → `main` / root）後，
網址是 <https://reynoldsliu.github.io/pixel-pond/>，推上去就等於更新線上版，沒有打包步驟。

要放到其他靜態主機時，`npm run pack -- <資料夾>` 只複製執行需要的檔案（不含測試、文件、工具）。

## 場景元素

預設配色「森林（範例）」照教學截圖取色：低彩度青綠水、黃綠草地。為了貼近範例的畫風：

- **光**：池塘周圍是受光空地，外圍是值雜訊做的大塊樹蔭，量化成 4 階；陰影偏藍綠、受光偏黃。
  物件依站立位置壓暗，地上有往右下的投影。
- **構圖**：左右與上緣有被裁掉的大樹框住畫面，岸邊一圈垂到水面的草，可選一條泥土小徑。
- **隨機構圖**：池塘的位置、大小、扁平度（視角）依種子變化，大池塘會被畫面邊緣裁掉；前景大樹的樹冠會從畫面下緣伸進來遮住部分水面。
- **天空**：預設上方約兩成是天空（漸層、會慢慢飄的積雲、兩層由一棵棵樹冠排成的遠方林線）。雲 60 秒飄過一個畫面寬，
  剛好是 12 個水面循環，所以有天空時錄影會錄 60 秒才接得起來，面板「天空比例」調到 0 就回到全地面的俯瞰。
- **水生動物**：水下游的魚影與錦鯉、來回划水帶 V 形水痕的鴨子、蹲在荷葉上會眨眼鼓喉的青蛙，面板「水生動物」控制。
- **透視與尺度**：越靠畫面下方（越近）的東西越大；樹的大小照現實分佈（小樹苗和草叢差不多、大樹樹冠能和池塘相比）。
- **寫實樹木**：不描外框；樹冠每個像素的亮度由整體受光、葉叢受光、葉簇雜訊與下半部遮蔽決定，量化成 7 階（暗部偏藍綠、亮部偏暖），邊緣打散成零碎葉片、內部有透光小洞；針葉樹有下垂的針葉紋，樹幹有縱向樹皮紋。
- **其他元素也寫實化**：香蒲葉從根暗到尖亮、部分折垂，穗是圓柱；荷葉有放射葉脈與捲邊、偶有泛黃，睡蓮花瓣分亮暗；綠頭鴨公母不同、有翼鏡與羽紋；
  石柱、斷牆、營火、鏟子、樹樁斧頭、水桶都用材質 7 階色畫形體、接縫斜面、裂縫、年輪、鏽斑與青苔，並隨距離縮放；火焰 5 色由白黃到暗紅。
- **樹的結構**：闊葉樹是樹幹 → 隨機 2–3 層分枝 → 枝梢長葉叢，看得到主枝與樹根；針葉樹的層數、左右長短、傾斜都隨機。
- **素材**：每種材質 5 階色（深色非黑外框、色相偏移），樹冠由一團團小葉叢堆成，針葉樹分層下垂，石頭長苔。

除了池塘，場景裡還有（都由 [src/sprites/library.js](src/sprites/library.js) 程式繪製，顏色跟著配色走）：

- 花草樹木：橡樹、松樹、灌木、草叢、小花、蘑菇、岸邊蘆葦——會**隨風擺動**（越靠樹梢擺越多，
  倒影跟著一起動），面板的「風力」控制。
- 石頭：岸邊大石、水中石頭、小碎石；立在水裡的東西旁邊與下方會有斷續的接觸亮線。
- 小徑：從畫面邊緣彎進來的泥土路。
- 地標：遺跡（石柱、斷牆）、火堆（火焰逐格跳動）、遺落工具（鏟子、樹樁上的斧頭、水桶），面板可勾選。

## 地區與生態（現實同步）

選一個地點（📍 用我的位置、常用地區、或用英文搜尋城市），場景就照當地生成：

- **地點 → 氣候**：Open-Meteo 給海拔、時區、即時天氣，以及去年一整年的逐日氣溫與雨量，算出柯本氣候分類（例：台北 Cfa、開普敦 Csa）。
- **氣候 × 地理區 × 季節 × 水域 → 物種**：[src/core/ecology.js](src/core/ecology.js) 的物種表只放當地原生或長期歸化的種類，例如企鵝只在南半球海岸、錦鯉只在東亞的公園池塘、仙人掌只在美洲、海水裡不會有睡蓮和青蛙、冬天的落葉樹是光禿的。南半球的季節是反的，熱帶沒有四季。
- **GBIF 確認**：按「用 GBIF 確認附近真的有」，逐一查候選物種在 100 km 內的實際觀察紀錄，0 筆的就排除。面板會列出畫面裡每個物種、出現的理由與紀錄筆數。
- **時間**：依當地太陽高度換成清晨、黃昏或夜晚的配色；開「即時同步」後每 10 分鐘更新一次，下雨會有漣漪，風大樹會搖（桌布模式也會更新）。
- **水域**：池塘、大型湖泊（對岸很遠、有湧浪）、海岸（沙灘、碎浪、沖上沙灘的浪）、海洋。
- **鳥**：麻雀類會跳著覓食、鷺會涉水或突然啄魚、翠鳥從岸邊俯衝、燕子貼著水面飛、猛禽盤旋、鷗會盤旋、站在沙灘或浮在海上、鸕鷀會潛水、鴴追著浪跑、企鵝在沙灘上走。每張圖的行為都是隨機挑的。

隱私：只有按按鈕或開即時同步時才連線；位置只保留到小數一位（約 10 公里）再放進網址。

## 面板

分成五組，可收合：**場景**（配色、構圖滑桿、地標、seed）、**水面與動態**（動畫參數、六步打磨開關）、
**風景照轉換**、**素材圖與像素化**、**輸出與桌布**（解析度、FPS、Plash 網址、PNG／影片）。最上方是一句話描述與「換一個場景」。

## 風景照轉換

在「風景照轉換」選一張照片，畫面會換成那張照片的動態像素版：

1. 依畫面比例裁切、縮成像素畫，中位切割減色；調色盤做「暗部偏藍綠、亮部偏暖黃」的色相偏移，再依「配色風格強度」
   往目前配色的色相靠（換成黃昏、夜晚配色，照片也跟著變）；孤立的雜點換成周圍的顏色，留下乾淨的色塊。
2. 自動找水面：偏藍/青、不和頂端天空相連的區塊，加上畫面最下方常見又不偏暖的顏色（灰暗的海、陰天的湖）。
   找不準時調「水面偵測靈敏度」，或把「水線位置」拉到水面上緣（以下不偏暖的像素都算水）。
3. 水面套用教學的動態：逐行整像素錯開（照片裡的倒影會跟著晃）、亮點、漣漪，一樣 5 秒無縫循環。
4. 雲飄動：從最上排沿「偏藍或很亮」的像素找出天空，和每排天空底色差很多的就是雲；雲從底圖抹掉、鏡像接成兩倍寬，
   120 秒往右飄一圈，只畫在天空像素上（會從樹、山後面經過）。下緣貼著地面的亮塊（遠山、霧中的島）不算雲；
   天空裡雜色太多（亮岩壁、陰天）就不拆。可在面板關掉。
5. 植物擺動：偏綠的像素依「風」滑桿左右擺 1–2 像素，只從植物像素取樣，不會把天空拉進樹裡。

選了照片後畫面下方會出現「✕ 取消照片」，一鍵回到程式場景。

照片只存在當下分頁，桌布網址不會帶著它；要當桌布請「錄影片」。程式在 [src/scenes/photo.js](src/scenes/photo.js)。也可以直接把照片拖到畫面上。

## 圖片像素化

面板的「圖片像素化」可以把任何圖片（照片、AI 生成圖、手繪）轉成像素畫：

1. 依面積平均縮到指定寬度（透明度先乘進顏色，邊緣不發黑）。
2. 去背（選填，支援複雜背景）：簡化版 GrabCut，不用 AI 模型、離線可跑。外框留白一定是背景；主體、背景各用 5 群高斯描述顏色，
   加上「相鄰同色該同一邊」與「越靠中央越像主體」，反覆估計 6 輪，最後只留大塊主體、補掉內部的洞。
   主體需大致在畫面中央；主體貼近邊緣時把「外框留白」調小。實測在風景照背景上 IoU 約 0.8–0.95。
3. 中位切割取指定顏色數的調色盤，每個像素挑最近色；勾「抖動」會加 4×4 Bayer 規則網點。

預覽本身是動態的（水面、雲、植物照風景照的規則動，像素不再減色、透明保留）。
結果可以下載 PNG（檔名已照素材規則），選好用途直接「加入場景」（後方樹木、花草、岸邊、水中石頭、地標、地面底圖），
或按「做成動態畫面」把原圖整張當風景照轉換。加錯了按「↶ 復原上一次加入」，或「清除上傳的素材」回到 assets/ 資料夾的素材。
加入的圖和上傳一樣只存在當下分頁；要當 Plash 桌布，把下載的 PNG 放進 `assets/` 再跑 `npm run assets`。
演算法在 [src/image/pixelate.js](src/image/pixelate.js)，純函式，Node 也能跑。

## 換成自己的素材圖

照 `<分類>-<用途>-<名字>.png` 命名（例如 `flora-back-oak.png`、`prop-feature-campfire.png`）放進
[assets/](assets/README.md)，執行 `npm run assets` 產生清單即可；只換一部分也行，沒換的用途照樣由程式畫。
`npm run assets:builtin` 會把內建素材輸出成 PNG 範本。也可以在面板直接上傳試看（只存在當下分頁）。

## 程式架構

```
src/
  index.js            對外 API（瀏覽器、Node 測試、tools/ 都從這裡拿）
  core/               純資料與小工具，不依賴其他層
    config.js         配色、預設值、循環長度、設定驗證（sanitize）、網址編碼
    prompt.js         一句話 → 設定差異（關鍵字規則）
    color.js math.js  顏色、亂數、雜訊、距離場
    ecology.js        地點 → 生物地理區、柯本氣候、季節、太陽高度 → 會出現的物種（附理由）與配色
  image/pixelate.js   縮圖、減色、抖動、去背
  assets/naming.js    素材檔名規則、裁透明邊
  sprites/library.js  程式畫的素材庫（樹、石頭、遺跡…）
  scenes/             場景 = build（產生純資料）+ render（只依時間畫一格）
    index.js          依 scene.type 分派的註冊表
    photo.js          風景照場景；effects.js 是共用的色階與漣漪、亮點畫格
    pond/             水域場景（池塘、大型湖泊、海岸、海洋），依圖層拆開：
      index.js        組裝 build 順序與每幀的 pass 清單
      layout.js       池塘形狀、深度、透視、光照
      terrain.js      草地、小徑、土坡、天空、林線、雲
      objects.js      樹、花草、岸邊、地標、投影、風
      water.js        教學六步的水面（色號階段）、湖海的湧浪、海岸碎浪、水線、落葉
      life.js         荷葉、魚、錦鯉、鴨子、青蛙
      birds.js        鳥：依類型隨機的行為（跳、啄、涉水、潛水、盤旋、追浪…）
  ui/                 唯一碰 DOM 的地方
    stage.js          緩衝畫布、整數倍放大、fps 上限的動畫迴圈
    art-library.js    素材集合（不可變快照，可復原）
    panels/*.js       每個面板一個檔案，只透過 app 溝通
    i18n.js           介面語言（中文 / English）：t('中文') 查對照表；?lang=en|zh 或右上角按鈕切換
    realworld.js      免費 API（Open-Meteo 天氣／氣候／地名、GBIF 觀察紀錄）與「此刻的場景設定」
  main.js             組裝 App（狀態 + 事件），掛上面板
```

相依方向只能往下：`ui → scenes → image/sprites/assets → core`。下層不碰 DOM，所以 `npm test` 在 Node 直接跑。
面板之間不互相 import，改一個面板不會牽動其他面板；App 用事件（`config`、`scene`、`photo`）通知。

## 擴充點

- **描述文字 → 參數**：[src/core/prompt.js](src/core/prompt.js) 的 `PROMPT_RULES` 關鍵字表（中英文皆可）。想接 LLM，
  只要把 `parsePrompt(text)` 換成呼叫你的 serverless API，回傳同樣的 `{ patch, matched }`。
- **新場景**（雪地、海邊…）：寫一對 `buildXxx()` / `renderXxx()`，在 [src/scenes/index.js](src/scenes/index.js) 的 `RENDERERS` 登記 `type`，
  場景物件帶 `type`、`W`、`H`、`period`（完整循環秒數，錄影會錄整數圈），既有程式不用改。
- **新的程式素材**：在 [src/sprites/library.js](src/sprites/library.js) 的 `LIB` 加一個產生器，名字照素材命名規則，再加進 [src/scenes/pond/objects.js](src/scenes/pond/objects.js) 的 `pickTables` 或 `FEATURES`。
- **新物種**：在 [src/core/ecology.js](src/core/ecology.js) 的 `SPECIES` 加一行（地理區、氣候、水域、選填的緯度/季節限制與理由）。外觀沿用 `kind`（例如 `tree:palm`、`bird:gull`），新外觀才需要新的素材或 `birds.js` 的類型。
- **池塘的新效果**（螢火蟲、雨絲…）：寫一個 `paintXxx(S, out, ctx)`（或改水色號的 `toneXxx(S, ctx)`），
  加進 [src/scenes/pond/index.js](src/scenes/pond/index.js) 的 `PAINT_PASSES` / `TONE_PASSES`；需要預先算的資料寫一個 `buildXxx(S)` 接在 build 最後
  （所有圖層共用同一個種子亂數，接在最後才不會改到既有畫面）。
- **新面板**：在 `src/ui/panels/` 寫一個 `mountXxx(app)`，加進 `main.js` 的清單。
- **配色**：在 [src/core/config.js](src/core/config.js) 的 `PALETTES` 加一組即可出現在選單。

後續規劃見 [docs/ROADMAP.md](docs/ROADMAP.md)。
